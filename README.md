# Libala Gold Agribusiness Limited

**From the Plains of Sesheke to the Nations**

Website and brand kit for Libala Gold Agribusiness Limited, an agricultural start-up on the Zambezi plains of Sesheke, Western Province, Zambia.

- **Website:** `index.html` (served by GitHub Pages from this repository's root)
- **Brand kit:** [`brand-kit/`](brand-kit/)

## Brand kit contents

| Folder | What's in it |
|---|---|
| `brand-kit/logos/transparent/` | Full logo, crest (name + emblem), emblem only, horizontal lockup and tagline as transparent PNGs. Each in colour, reversed-for-dark, white, gold, green and black. |
| `brand-kit/logos/web/` | Smaller PNGs sized for websites and email (300 / 600 / 1200 px wide). |
| `brand-kit/logos/on-background/` | JPGs on white, cream and green backgrounds for places that don't accept transparency. |
| `brand-kit/favicons/` | `favicon.ico` (16–256 px), Apple touch icon, Android/PWA icons, maskable icon, `site.webmanifest`. |
| `brand-kit/social/` | Profile pictures and cover images for Facebook, Instagram, LinkedIn, X, YouTube, WhatsApp, plus a link-share image and a presentation title slide. |
| `brand-kit/documents/` | Word letterhead (sample and blank) and a branded multi-page document template, with PDF previews. |
| `brand-kit/email-signature/` | Small logo for email signatures. |
| `brand-kit/source/` | The original logo artwork and the scripts that generate every asset. |
